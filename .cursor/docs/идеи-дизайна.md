## Круги статов (стиль фэнтезийной таверны)

Не делать просто залитый цветной круг. Для интерфейса в стиле фэнтезийной таверны интереснее собирать каждый круг слоями:

1. **Внешняя тёмная обводка**
2. **Цветной градиент** (основной → тёмная часть)
3. **Мягкий внутренний свет**
4. **Небольшой блик**
5. **Центральная белая / светло-серая эмблема**
